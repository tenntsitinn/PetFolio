# 气泡边界弹性位移

2026-10-20：根据双屏试用反馈，气泡跨屏时保持刚体形状，用位置回弹表现与屏幕边界的交互。

`PetPanelSpring.Track` 持续跟踪气泡相对宠物的目标偏移。普通拖动时偏移不变，宠物移动立即传递给气泡；边界约束、跨屏或左右换侧改变偏移时，使用现有弹簧参数（stiffness 420、damping 20、mass 0.7）过渡。动画中目标再次变化保留当前速度。窗口、背景与关闭按钮使用同一帧位置，不缩放内容。

最终绘制位置仍限制在当前工作区内。因此靠近边界时气泡被挡住，目标移入可用空间后释放并回弹；不会为展示弹簧超调而把气泡甩出可用区域。首次显示、隐藏后重现、更换宠物窗口和显示配置变化会清除旧动画。手动拖动气泡保持直接跟手，松手沿用原有回位。

原生参考为本地已有的 Codex 26.1013.3656.0 调查材料，其中通知容器以宠物位置为基准，单独对相对 x/y 使用 spring transition。本实现将该方式适配到 PetFolio 的左右布局；尚未通过双屏录像逐帧核对，不声称与原生视觉完全一致。

验证覆盖首次显示、普通跟随、边界挤压与释放、回弹收敛、连续目标反转、跨屏换侧及新屏边界约束。`PetTrackingTests` 的单屏 DPI 测试改用注入的单屏快照，避免接入真实第二屏后改变测试前提。

实机验收重点：慢速与快速跨屏往返、边缘停住后反向拖回、上下排列、不同 DPI，以及 Default / Pet colour 的背景和阴影是否保持同步。

本轮验证：61 项布局检查、144 项点击与实际窗口动画检查、38 项单屏跟踪、16 项多屏跟踪和 153 项窗口层级检查通过，其余非下述测试也通过。设置测试使用项目内临时目录运行，避免系统临时目录的文件替换失败。`TrayOverlapTests` 的悬停按钮可见性及 `BubbleMaterialTests` 的外阴影像素断言仍失败；独立临时构建撤去本次动画接入后，两项在相同断言失败，不能将本轮记录为全套通过。

独立测试程序：`.test-build/edge-spring/PetFolio.exe`，未覆盖运行中的程序。
