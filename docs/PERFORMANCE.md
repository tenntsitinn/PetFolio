# 常驻性能测量

**后续已完成五组交替长测。** 每个场景预热 10 秒、测量 30 秒，包含原生鼠标输入回放，见 [完整长测与跟随抖动修正](CONTROLLED_BENCHMARK.md)。下面保留早期六秒短样本供追溯，当前判断应以长测为准。

本次记录日期：2026-10-12。使用 `./profile.ps1 -Seconds 6`，每个阶段预热两秒、测量六秒；窗口使用生产 tracker、feature、WinForms／Composition 和系统计数器，宠物发现及额度响应使用夹具。五个情境依次为静止额度、保存位置持续变化、20% 不透明度系统模式、手动隐藏气泡、宠物关闭。

工具使用隔离配置及独立窗口，不访问真实账号，不移动鼠标，不修改 Codex 设置。移动情境每 100 ms 更新夹具保存位置，测量跟随路径；它不能替代实际鼠标拖动或混合 DPI 现场验证。夹具写入及消息循环成本也计入测试进程。CPU 是**一个逻辑核心的占用百分比**，不是整机百分比；不包含 DWM／GPU 或真实 CLI 子进程。内存为阶段结束时的工作集。

前后单次短样本中的 CPU 会受系统负载、窗口合成和调度影响。移动情境另一次优化后测量为 4.42%，最终复测为 8.31%，因此**目前不能判定移动时 CPU 得到改善**。静止及隐藏时的解析／重复快照消除由行为测试验证；CPU 表格是本机观测，不是性能保证或 CI 门槛。静止前后均无重复帧绘制；此次优化没有减少已经不存在的重复绘制。

主要变化：配置文件按修改时间及长度缓存解析；只有目标、位置、尺寸、可见性、拖动状态、宠物 ID 或颜色变化才发布状态；静止跟踪间隔为 100 ms，实际拖动为 16 ms。气泡独立交互计时器保留悬停及吸附：隐藏时停止，静止可见时为 100 ms，拖动／吸附时为 16 ms。系统模式保持两秒采样，隐藏或关闭宠物时停止；最终测量的系统模式六秒内采样／取色三次，隐藏及宠物关闭时取色为零。

基线 JSON 中 Windows 6.2 是旧 manifest 下的兼容版本字符串；最终复测通过 `RtlGetVersion` 识别实际 Windows build 26200，16 个逻辑处理器。原始数据：[基线](performance/before.json)、[初次优化](performance/after-initial.json)、[最终复测](performance/after.json)。

复测命令：

```powershell
./profile.ps1 -Seconds 8 -OutputFile .test-build/performance.json
```

`Seconds` 支持 2～30 秒，每次都会重新建置隔离探针。真实 Codex 拖动、客户端升级、长时间资源增长和混合 DPI 的完整验证仍需另行进行。
